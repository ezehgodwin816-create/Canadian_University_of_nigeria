FLOATING AI + THEME BUTTONS – FIX PACKAGE
=========================================

Upload / replace these 3 files in your GitHub repo:

1. css/style.css          (contains the floating button styles)
2. js/theme-anim.js       (creates & controls the buttons)
3. index.html             (includes the buttons + loads the script)

After upload:
- Hard refresh the page (Ctrl+Shift+R or Cmd+Shift+R)
- You should see two circular buttons on the bottom-right:
    ☀ Theme   and   ✦ AI
- Long-press either button → "Hide for now" / "Cancel"
- Refresh the page → buttons reappear

If they still do not appear:
- Open browser DevTools (F12) → Console and check for red errors
- Confirm the files are at:
    /css/style.css
    /js/theme-anim.js
    /index.html
